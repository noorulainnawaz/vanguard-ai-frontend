# Vanguard AI — Frontend

**AI-Powered Cybersecurity Risk & Decision Platform (Web App)**

## What This App Does & The Problem It Solves

Most individuals and small organizations have no easy, affordable way to understand their real cybersecurity exposure. Professional security audits are expensive and slow, and generic advice online doesn't account for a specific person's or company's actual situation.

**Vanguard AI** solves this by giving anyone — a student, a small business owner, an employee — an instant, AI-driven cybersecurity assessment. Users answer a few simple questions about their digital habits (passwords, 2FA, phishing awareness, company security posture, etc.) and the platform's AI engine scores their risk, explains *why*, and generates personalized, actionable recommendations — the kind of insight that would normally require hiring a security consultant.

It also includes an AI-generated attack-story simulator and cybersecurity learning lab generator, so users can *learn* about threats (ransomware, phishing, SQL injection, etc.) in plain language, not just get scored on them. A separate, hidden admin console lets an operator monitor all users, organizations, and platform activity.

## 🔐 Admin Console

The admin console (`/system-access-portal`) is a completely separate, isolated authentication system — it is intentionally **not linked anywhere** in the normal UI, and normal user accounts cannot access it (it uses its own isolated `admins` database table and its own login endpoint, entirely separate from regular user login).

For security, live admin credentials are not published here. See the **Screenshots** section below for the admin console in action (stats overview, user management, and per-user activity monitoring).

## Features List

- **Landing page** with feature overview, "how it works", and about sections
- **Register / Login** — email + password, plus **"Sign in with Google"**
- **Forgot Password** flow
- **Mission Control Dashboard** — overall risk score, per-category risk cards, bar chart comparison, recent attack stories, recent AI decisions, security timeline
- **AI Chat Assistant** — text chat with the AI, with conversation history, plus **voice input (microphone)** and **voice output (text-to-speech)**
- **Identity Risk, Human Risk, Insider Threat** — dedicated input forms, each returning an AI-generated score + recommendations
- **Attack Story Generator** — pick an attack type/industry/company size and get a full AI-generated attack timeline
- **Cyber Lab Generator** — pick any security topic and difficulty, get a full AI-generated learning module + quiz
- **Security Decision Engine** — CISO-style roadmap generator for a company's profile
- **Attack Surface Visualizer** — map of digital assets and their exposure/risk heatmap
- **File Analysis** — upload a file and get an AI-driven security review
- **Reports Center** — generate an AI executive summary report and download it as a PDF
- **Profile page**
- **Fully separate, hidden Admin Console** (`/system-access-portal`) — not linked anywhere in the normal UI:
  - Platform-wide stats (users, orgs, reports, average risk scores)
  - User management table (promote/demote/delete)
  - Organization list
  - Per-user activity viewer (their chat history + full risk assessment history)
  - Send a direct message to any user

## The AI Feature — What It Does & The Prompts Behind It

Every risk score, report, attack story, cyber lab, and chat reply on this frontend is generated by calling the backend, which in turn calls **Google's Gemini API** (`gemini-2.5-flash`) with prompts written specifically for that feature — not generic "chatbot" prompting.

**Example — the AI Chat Assistant's system framing (with context memory):**
```
You are Vanguard AI, a professional cybersecurity assistant. Continue this
conversation naturally, remembering what was said before.

Conversation so far:
{last 10 messages from this session}
Vanguard AI:
```

**Example — the Cyber Lab Generator prompt:**
```
You are a cybersecurity training content creator. Create a structured learning
module on the topic "{topic}" for {difficulty} level learners.
Respond ONLY in this exact JSON format... (title, learning_path, objectives,
explanation, hands_on_exercise, expected_outcome, quiz, recommendations)
```

The frontend sends the user's actual form inputs to the backend, which builds these prompts dynamically, calls Gemini, parses the structured JSON response, and returns it to the UI to render as cards, charts, and timelines — so the AI's output directly drives the visual experience, not just a text box.

## Tools, Services & Models Used

- **Frontend:** React + Vite + Tailwind CSS v4 + React Router
- **Charts:** Recharts
- **Voice:** Browser Web Speech API (SpeechRecognition + SpeechSynthesis)
- **Auth:** JWT-based session (stored in localStorage) + Google Identity Services (OAuth)
- **AI Model/Provider (via backend):** Google Gemini API (`gemini-2.5-flash`)
- **Backend:** FastAPI (see companion backend repo)
- **Database:** Supabase (PostgreSQL)
- **Hosting:** Vercel (frontend), FastAPI Cloud (backend)
- **Editor:** Antigravity (VS Code-based)

## How to Run This Project Locally

1. Clone this repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. The API URL is configured directly in each page's `API_URL` constant, currently pointing to the live backend (`https://vanguard-ai.fastapicloud.dev`). To point to a local backend instead, change these to `http://127.0.0.1:8000`.
4. Run the dev server:
   ```bash
   npm run dev
   ```
5. Open the URL shown in the terminal (usually `http://localhost:5173`)
